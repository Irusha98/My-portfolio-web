Proxmox lab AI agent

A virtualisation lab built on an HP ProLiant DL360p Gen8 running Proxmox VE, with OPNsense handling firewall and routing over Linux bridges. Ubuntu Server VMs provide DHCP, DNS, NTP and SSH, followed by Docker services such as Portainer, Nginx, PostgreSQL and Redis. On top of it I built an AI agent that communicates with OPNsense and the Ubuntu server through their APIs, using Google ADK and the Gemini API.

Network AI tool

An AI tool that makes a network engineer's job easier. Instead of remembering complicated commands, you have a simple conversation and say what you need configured on a device, and the AI carries it out. To check VLANs, just type "hey give me vlan details", with no need to worry about device modes.

The network devices run in Cisco Modeling Labs (CML) using Cisco, Cisco DevNet and Cisco Networking Academy resources. Ollama provides the AI, and the whole tool is a Python script.
